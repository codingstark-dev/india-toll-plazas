# India Toll Plazas List (2026)

A list of **1,294 National Highway toll plazas** across 25 states of India, with state, district and highway, in JSON and CSV.

**Current toll rates, monthly pass prices and a trip toll calculator:** [raahguide.com](https://raahguide.com)

## Fields

| Field | Notes |
|---|---|
| `name`, `state`, `district`, `highway` | Plaza location (e.g. NH-16) |
| `url` | Plaza page on [raahguide.com](https://raahguide.com): car, bus and truck rates, return and monthly pass prices, in English and Hindi |

- `tolls.json`: one record per plaza
- `tolls.csv`: the same data as CSV

## Toll rates

Rates change every year on 1 April, so they aren't kept in this file. You can get the current rate for any plaza:

- open its `url`, or
- search by highway, state or route on [raahguide.com](https://raahguide.com).

## Source

Compiled from NHAI's public toll information ([tis.nhai.gov.in](https://tis.nhai.gov.in)), last checked **23 Nov 2026**. Not affiliated with NHAI or the Government of India.

If you use this list, please link back to [raahguide.com](https://raahguide.com).
